DDoS Protection System For Cloud

A DDoS Protection System for cloud environments detects, analyzes, and mitigates distributed denial-of-service attacks in real time using a hybrid approach of rule-based filtering, behavioral (anomaly) detection, and adaptive mitigation (rate-limiting, traffic scrubbing, blacklisting). The system integrates with cloud load balancers and WAFs, provides dashboards and alerts, and automatically applies countermeasures to keep services available while minimizing false positives.

Secure Closed Group Communication

The Secure Closed Communication Platform ensures safe and private communication for defence personnel and their families over public mobile networks. It uses a client-server architecture with end-to-end encryption (AES & RSA), secure authentication (OAuth 2.0, OTP-based login), and role-based access control to maintain confidentiality and trust. The platform supports text, voice, and file sharing with strong data protection and real-time message encryption, ensuring communication remains secure even on public networks.

Smart Blind Stick

The Smart IoT Blind Stick is an assistive device designed to enhance the mobility and safety of visually impaired individuals using modern IoT and sensor-based technologies. The stick detects nearby obstacles, water puddles, and changes in terrain using ultrasonic and IR sensors, and alerts the user through vibration or audio feedback. Additionally, it features GPS and GSM modules for real-time location tracking and emergency alerts, ensuring user safety during outdoor movement.
